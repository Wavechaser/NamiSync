Distribution notice supplements
===============================
This directory contains verbatim upstream license/notice files that supplement
the existing About records in namisync/interfaces/web/assets/legal_content.js.
manifest.json records component versions, exact source locations and SHA-256
hashes of these files. Keep upstream text unchanged; refresh deliberately when
the selected build inputs change. Numbered filenames give stable output order.
Temporary downloads, source archives and investigation evidence belong under
ignored build/, not here. Remove superseded supplements when their component is
no longer included. notices.py exports both corpora into THIRD-PARTY-NOTICES.txt.
The selected Python Windows installer license includes notices for optional
components not collected by this app; retaining the complete upstream file does
not imply those components are shipped.
SQLite's file is the complete leading comment of the pinned sqlite3.h; its
full header is retained in preparation evidence, not a second source copy here.
XZ supplies liblzma only: its public-domain library, not the GPL/LGPL tools or
build utilities mentioned in its complete upstream COPYING file.
