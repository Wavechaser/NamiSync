# EV-0040: M2-A2 spike results (2026-11-24)

Live checks for checkpoint M2-A2. They are diagnostic observations that inform
designs, not acceptance results; each conclusion is recorded in its feature's
entry in [M2_PLAN](../../docs/M2_PLAN.md). Origin: `build/m2-a2/` at
`9bb58fa9`. Each `REPORT.md` was written from the builder's report and spot-
checked against the raw files beside it.

Profile: the PERFORMANCE reference machine (Windows 11 Pro 26200), with CPython
3.13.17 and SQLite 3.50.4 from the development `.venv` rather than the release
interpreter. pywebview 6.2.1, WebView2 SDK 1.0.3856.49, runtime 157.0.4341.60.
Other spikes and test runs shared the machine.

| Folder | Spike | Files |
| --- | --- | --- |
| `volume/` | Volume overview queries: elevation, spin-up, deadline | report, unelevated probe results, spin-up latency run and its scripts |
| `framing/` | Content in the caption area with the native frame | report, hit-test table for the chosen mode, Snap Layouts screenshot |
| `drop/` | Drag-and-drop paths from WebView2 | report, synthetic-drop log |
| `notify/` | Completion notification registration | report (includes the user-watched banner test) |
| `stop-latency/` | Stop's cancel-to-release time | report, raw samples (F: NVMe warm and fresh-process; J: HDD warm; plan compute), harness and analyzer |

Reproduce the stop-latency statistics with
`python stop-latency/analyze.py stop-latency/samples_J_warm.json`. The HDD
fixture is generated by `harness.py gen` with seed `0x4E414D49`.
